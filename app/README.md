# Feed Me Token

桌面挂机小游戏原型。MVP 从本机 Codex 会话日志读取 `total_tokens` 增量，每 1,000 token 兑换一根能量棒。显示器头机器人从右侧走入，前 20 波默认一击倒下；角色自动吃棒、伸手发射短射线，击败后获得金币和经验，下一只随即入场。初次启用从零开始，不导入历史用量。

## 本地开发

需要 Node.js、Rust 和 Tauri 2 对应平台的系统依赖。

```sh
npm ci
npm run tauri dev
```

前端独立预览：

```sh
npm run dev
```

浏览器预览使用独立的 5 根模拟能量棒，不读取或修改 Codex 数据。原生应用在每次启动和之后每 60 秒刷新 Codex 记录，也可点下方控制栏的刷新按钮。

## 操作

- 拖动战斗场景移动窗口；下方控制栏可刷新、展开状态、切换置顶与声音、最小化及退出。
- 在状态面板选择“薄荷机房”“蜜桃终端”或“插画动作版”皮肤；原生程序会保存选择，浏览器预览使用浏览器本地存储。插画动作版的主角在待机、取棒、吃棒、鼓腮、发射和胜利阶段使用非像素透明图集；机器人与机器仍是像素占位美术。
- 金币足够时购买攻击升级。托盘菜单提供显示、隐藏与退出。
- 状态只保存在本机应用数据目录；不读取对话正文，不需要安装 ccusage，也不需要网络连接。

## 验证

```sh
npm run build
cd src-tauri
cargo test --offline
```

Windows 原生运行环境需要 WebView2。macOS 透明窗口、托盘和发行包仍需在真实 Mac 上验收。主角、机器人、机器和能量棒已改为可替换的 PNG 图集；主角造型见[角色美术设定](../docs/Feed-Me-Token-角色美术设定.md)，替换方法见[皮肤资源说明](../docs/皮肤资源说明.md)，详细范围见[实施文档](../docs/Feed-Me-Token-MVP-实施文档.md)。
