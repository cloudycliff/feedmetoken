# Feed Me Token：角色美术设定

> 状态：主角造型 v1 已选定（2026-09-29）。用于指导后续精灵完善；远程攻击方向已确认。

## 已选定的主角造型

用户认可[主角概念稿 v1](./art/hero-v1-concept.png)作为当前设计依据。该图由已配置的图像中转接口使用 `gpt-image-2` 生成；[提示词与参数](./art/hero-v1-concept.prompt.txt)随图保存。保留圆脸与鼓腮、深色短发和一缕翘发、宽松青绿外套、珊瑚色零食袋、琥珀色包装能量棒以及轻松贪吃的表情。概念稿是造型参考，游戏内像素精灵按统一网格重新绘制，不直接缩小高分辨率图片。

当前 `app/public/skins/` 的两套内置皮肤已共用这一造型的首轮像素适配，仅配色不同。人物动作帧槽为 **96×80 逻辑像素，脚底锚点为 `[48, 74]`**；包括待机睁眼/眨眼、伸手/收回、咬下/鼓腮、蓄光/发射、胜利九个姿势。可编辑绘制源为 `app/tools/draw_hero_v1.py`。这是一轮可玩精灵，细部和节奏仍可根据试玩调整；机器人、机器与场景还沿用占位图。

[查看九姿势像素预览](./art/hero-v1-pixel-poses.png)。

## 核心印象

主角是一个贪吃、圆润、好奇心旺盛的三头身卡通小女孩。她把封装成零食的 token 能量棒当作最喜欢的食物：平时有点困倦，看见能量棒立刻眼睛发亮，吃下后腮帮鼓起，再伸手射出短促能量射线，对付闯进来的机器人。性格的转变要靠短动画读懂，不依靠对白。

用户提到的角色只作气质参考：保留“吃电子物品”的荒诞趣味和圆润可爱感。主角的轮廓、发型、服装、配色、表情与动作需形成自己的识别度。

## 主角造型建议

| 部位 | 建议 |
| --- | --- |
| 比例 | 总高约三个头；较大的圆脸、短小四肢，侧面能清楚看到嘴巴与鼓起的脸颊。 |
| 轮廓 | 短发与一缕弯曲翘发，宽松短外套，侧腰挂一个能量棒小袋；避免复杂装饰在小尺寸下变成噪点。 |
| 表情 | 待机半眯眼、看见食物时双眼发亮、咀嚼时鼓腮、攻击时短暂认真、胜利时满足地擦嘴。 |
| 配色 | 暖白与青绿为主体，少量珊瑚色作脸颊和动作强调；深蓝灰用于外轮廓。能量棒以琥珀黄区分。 |
| 动作道具 | 能量棒有容易撕开的包装与简洁的数据纹理；不印真实 agent 标志。 |

角色攻击时面向右侧，待机姿势允许微侧面。早期草案曾建议 64×64 帧画布；当前皮肤系统使用 96×80 帧槽，以容纳伸手和翘发，锚点见上。实际站姿高度约 74 像素；后续改动保持帧槽与脚底锚点稳定。

## 机器人敌人

敌人是头部为方圆角显示器的人形小机器人，身躯与四肢比头小，整体与主角体量接近。屏幕以极简像素眼口表达挑衅、受击和关机；深蓝灰机身加少量警示红。外形偏玩具机器人，不需要写实金属细节。第一版只有一个类型，可用屏幕表情和进场姿势增加变化。

## 动画动作表

| 对象 | 动作 | 读懂动作的关键帧 |
| --- | --- | --- |
| 主角 | 待机 | 呼吸、眨眼、偶尔看向能量棒入口。 |
| 主角 | 吃棒 | 看见 → 伸手 → 拆开 → 大口咬 → 鼓腮咀嚼。 |
| 主角 | 攻击 | 咽下 → 手掌亮起 → 伸手发射短促能量射线 → 收势。 |
| 主角 | 胜利 | 抿嘴满足或擦嘴，不做长时间遮挡桌面的庆祝动画。 |
| 机器人 | 入场 | 从右边走来，屏幕露出挑衅表情。 |
| 机器人 | 待机 | 屏幕闪烁，身体轻微晃动。 |
| 机器人 | 受击 | 射线命中后屏幕出现像素乱码，身体后仰和短暂闪白；表现“正在被破解”。 |
| 机器人 | 消失 | 屏幕熄灭，零件或像素点轻量散开。 |

吃棒和咀嚼应是整套动画的记忆点；攻击靠伸手、射线和屏幕乱码三个连续反馈读懂。射线只短暂出现，不持续横穿桌面。全程在 2 倍放大、没有声音的情况下也应清楚。

## 后续美术制作要求

以已选定的单人概念稿为基线，补充角色设定板：标准站姿正面与侧面、五个表情、吃棒/攻击两个关键姿势、主色板。然后制作机器人设定板。概念稿可以是较高分辨率的平面插画，最终像素精灵需按统一网格重绘。逐帧动画由同一角色结构制作，避免发型、身高和服装在帧间漂移。

可供图像生成或画师使用的原创概念提示：

> 为一款桌面像素宠物游戏设计原创三头身卡通小女孩。她圆脸、短发、脸颊容易鼓起，穿简洁宽松短外套，侧腰挂零食袋；看到发光的琥珀色能量棒时眼睛发亮，吃下后伸出一只手射出短促的像素能量射线，让玩具般的显示器头机器人屏幕出现乱码。呈现正面、侧面和表情/动作小稿；暖白、青绿、珊瑚色与深蓝灰有限色板；轮廓清楚、轻松幽默、适合后续重绘为 96×80 像素帧槽中的精灵。无文字、无商标、无现有作品角色特征。

## 交付与验收

- 概念源文件和最终精灵源文件可编辑；游戏使用透明 PNG 精灵表及帧时长数据。
- 背景透明，最近邻放大后没有模糊边缘；动作锚点一致，攻击方向明确。
- 浅色和深色桌面壁纸、不同系统缩放下，主角口部、能量棒和机器人屏幕表情仍能区分。
- 主角、机器人、能量棒各有明显不同的轮廓和明度，角色动作不依赖细小文字说明。
